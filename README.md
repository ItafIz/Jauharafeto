# JauharaFeto

Webapp edukasi, kalkulator, dan skrining awal fetomaternal untuk pasien dan tenaga medis.

## Fitur MVP

- Homepage branding JauharaFeto
- Mode pasien
- Mode tenaga medis
- Kalkulator usia kehamilan/HPL
- Kalkulator BMI
- Kalkulator MAP
- Skrining awal preeklampsia
- Pustaka topik edukasi fetomaternal
- Disclaimer medis

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` atau port yang ditampilkan Next.js.

## Build production

```bash
npm run build
npm run start
```

## Deploy ke Vercel

1. Upload folder `jauharafeto` ke GitHub.
2. Buka Vercel → Add New Project.
3. Import repository GitHub.
4. Framework preset: Next.js.
5. Build command: `npm run build`.
6. Deploy.

## Catatan medis

JauharaFeto adalah alat edukasi dan skrining awal. Aplikasi ini tidak menggantikan konsultasi dokter, pemeriksaan langsung, guideline lokal, atau keputusan klinis individual.
